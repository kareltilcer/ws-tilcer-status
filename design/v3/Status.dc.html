The status system

Four states, precedence red › orange › green › unknown. Color is never the only cue — every state carries a distinct glyph and a text label, so it reads for colorblind users and screen readers alike (WCAG 2.1 AA).

The debounce affordance

Healthy · re-checking

One failed check doesn't flip a site red. Until the streak reaches the threshold (2), we hold the prior color and pulse the dot with a quiet 1 failed check · re-checking note — so a blip reads as "watching", never a false alarm.
deliverable · design:accessibility-review

Accessibility review — WCAG 2.1 AA

Contrast measured by rendering each oklch token to sRGB and computing the WCAG ratio against its real background — both themes. Normal text target 4.5:1, UI/large 3:1. All flagged failures were fixed by splitting a fill token from an AA-tuned text token.

v3 · feedback surfaces

The report surfaces

Reports introduce a second colour language to the dashboard: accent means “someone wrote to you” and never health. That keeps the unread badge legible next to a status pill, and it keeps the four report states out of the red/orange/green vocabulary entirely. The widget carries its own review — see Feedback widget.dc.html.
